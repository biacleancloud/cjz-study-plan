國二上 數學科 第二次段考 衝刺重點與題型全攻略

範圍：第二章 根式與畢氏定理 ＋ 第三章 因式分解 ｜ 目標穩拿 85 分以上

📄 開啟數學衝刺講義 Word 檔 ↗
【考點一】二次方根化簡與分母有理化 必考 15~20 分
• 乘除法則：$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$，$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ ($a \ge 0, b > 0$)
• 分母有理化：$\frac{c}{\sqrt{a}+\sqrt{b}} = \frac{c(\sqrt{a}-\sqrt{b})}{a-b}$（利用平方差公式消除根號）
⚠️ 易錯陷阱：$\sqrt{a^2} = |a|$！若 $a < 0$，則 $\sqrt{a^2} = -a$。千萬不能直接寫成 $a$！例如 $\sqrt{(-5)^2} = 5$。
即測即評：化簡 $\frac{4}{\sqrt{5}+1} - \sqrt{20}$ 之值為何？ 點擊看解析 ▼
【解題步驟】：
1. 分母有理化：$\frac{4(\sqrt{5}-1)}{(\sqrt{5}+1)(\sqrt{5}-1)} = \frac{4(\sqrt{5}-1)}{5-1} = \frac{4(\sqrt{5}-1)}{4} = \sqrt{5}-1$。
2. 化簡根式：$\sqrt{20} = \sqrt{4 \times 5} = 2\sqrt{5}$。
3. 合併同類項：$(\sqrt{5}-1) - 2\sqrt{5} = -1 - \sqrt{5}$。
答案：$-1-\sqrt{5}$
【考點二】因式分解四大武器（提公因式、乘法公式、十字交乘） 必考 25~30 分
• 武器 1：提公因式 $ma + mb = m(a+b)$（看到負號先提出變號）
• 武器 2：平方差 $a^2 - b^2 = (a+b)(a-b)$
• 武器 3：和/差平方 $a^2 \pm 2ab + b^2 = (a \pm b)^2$
• 武器 4：十字交乘法 $x^2 + (p+q)x + pq = (x+p)(x+q)$
💡 十字交乘口訣：拆兩頭、乘中間、湊係數、定符號！常數項為正，兩數同號（看一次項正負）；常數項為負，兩數異號。

國二上 理化科 第二次段考 衝刺重點與題型全攻略

範圍：第 3 章 波動與聲音 ＋ 第 4 章 光、面鏡與透鏡（康軒版） ｜ 目標穩拿 85 分

📄 開啟理化衝刺講義 Word 檔 ↗
【考點一】波的傳播、週期頻率與波速公式 秒殺基礎分
• 波速公式：$v = f \times \lambda$（波速 = 頻率 × 波長）
• 週期與頻率互為倒數：$T = \frac{1}{f}$，故 $v = \frac{\lambda}{T}$
• 鐵律：波速由介質決定（同介質波速必相同）；頻率由波源決定（波由空氣傳入水中頻率不變）。
⚠️ 常考陷阱：大聲喊叫（振幅大）並不會讓聲音傳得比較快！因為空氣介質沒變，聲速一樣！
【考點二】凸透鏡成像六大規律（段考決勝題） 考卷壓軸大題
• 物距 $p > 2f$ ➔ 像在 $f < q < 2f$，成倒立縮小實像（照相機原理）
• 物距 $p = 2f$ ➔ 像在 $q = 2f$，成倒立等大實像（複印機）
• 物距 $f < p < 2f$ ➔ 像在 $q > 2f$，成倒立放大實像（投影機、顯微鏡物鏡）
• 物距 $p = f$ ➔ 不成像（折射光平行，探照燈）
• 物距 $p < f$ ➔ 像在物體同側，成正立放大虛像（放大鏡）
• 凹透鏡：無論物體在哪，永遠成正立縮小虛像（近視眼鏡）！
